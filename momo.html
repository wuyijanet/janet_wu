Momo Virtual Pet

Momo Virtual Pet is an interactive digital pet project created with JavaScript, p5.js, HTML, and CSS. Users can interact with Momo through four actions: eat, sleep, work, and play. The project explores character-based interaction, simple game logic, and visual feedback through animation and UI design.

Development Process

The project started from a simpler early version that focused on the basic pet interaction structure. In the first stage, I built the core logic of the virtual pet system, including status values, action buttons, and simple visual feedback. This version helped me test whether the interaction flow was understandable.

After that, I refined the visual design and character animation. I redesigned Momo’s appearance, adjusted the layout, improved the UI styling, and created more specific action-based scenes such as eating, sleeping, working, and playing. This process helped me move from a functional prototype to a more complete interactive project.
