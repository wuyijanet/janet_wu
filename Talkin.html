UI/UX Design / Mobile App Concept

Talkin

Talkin is a language learning and community integration mobile application designed to help international students and newcomers improve language skills, build social connections, and adapt to new environments. By combining language practice, peer interaction, and community-based experiences, Talkin creates a supportive platform where users can learn and communicate through real-life interactions.

← Back to Portfolio

App Interface Design

Talkin includes four main interfaces that support the complete user journey: connecting with language partners, practicing languages through daily tasks, participating in community discussions, and managing personal profiles.

Poster Preview

This poster presents the concept, target users, key functionalities, user motivations, and potential barriers of Talkin. The project explores how digital platforms can support language learning and community integration by combining social interaction with personalized learning experiences.

Project Presentation

This presentation introduces Talkin, including its core functionalities, target users, user motivations, and barriers to adoption. It explains how the application supports international students and newcomers through language learning, social interaction, and community engagement.

Project Highlights

  • Designed a mobile application that combines language learning with community interaction.
  • Created interface designs for messaging, daily language practice, community forums, and user profiles.
  • Developed user flows that support language partner matching and personalized learning experiences.
  • Integrated social features such as discussions, events, and peer communication to encourage user engagement.
  • Focused on reducing social isolation and helping international users adapt to new environments.

Design Process

Talkin was designed to address the challenges faced by international students and newcomers when learning a new language and adapting to unfamiliar communities. The project focused on understanding user needs, analyzing motivations and barriers, and creating a digital experience that connects language learning with social participation.

  • User research and target user analysis
  • User motivation and barrier analysis
  • Information architecture and feature planning
  • Mobile UI wireframing and interface design
  • Social interaction and community experience design
