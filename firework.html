Interactive Firework Project 互动烟花项目

Interactive Firework is a hand-tracking creative coding project built with JavaScript, p5.js, ml5.js, HTML, and CSS. Users can control digital fireworks through hand gestures and explore playful motion interaction in real time. Interactive Firework 是一个基于手势识别的创意编程项目，使用 JavaScript、p5.js、ml5.js、HTML 和 CSS 完成。 用户可以通过手部动作控制数字烟花，体验实时互动与动态视觉反馈。

Current Version 当前版本

This refined version combines gesture recognition, dynamic particle animation, and interactive visual feedback. 当前版本结合了手势识别、粒子动画和互动视觉反馈，整体效果更加完整和稳定。

Firework 🎆

Interact with digital fireworks using your hands!

Extend your left index finger to create warm-toned fireworks. 💛

Extend your right index finger to create cool-toned fireworks. 🩵

Move your hands to guide the fireworks.

Bring your index and middle fingers together to freeze the fireworks in place.

Separate your fingers to let them burst into motion again!

Tools 使用工具

  • JavaScript
  • p5.js
  • ml5.js
  • HTML
  • CSS

Main Functions 主要功能

  • Hand tracking for live interaction 通过手势识别实现实时互动
  • Different firework color groups for left and right hands 左右手触发不同配色的烟花效果
  • Freeze and release movement through finger gestures 通过手指动作控制暂停与释放
  • Dynamic particle animation and motion feedback 动态粒子动画与视觉反馈

Project Highlights 项目亮点

  • Connected hand movement with real-time visual animation. 将手部动作与实时视觉动画结合。
  • Explored interactive design through machine-learning-based gesture recognition. 通过机器学习手势识别探索互动设计表达。
  • Improved the earlier version into a cleaner and more polished portfolio piece. 在初版基础上优化为更完整、更适合作品集展示的版本。

Version 1 版本 1

The first version focused on the basic firework interaction and initial visual testing. 第一版主要展示基础烟花互动逻辑和最初的视觉实验效果。
