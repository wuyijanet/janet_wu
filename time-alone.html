Visualizing Time Spent Alone 独处时间数据可视化

A group coding and data visualization project using Python to process and visualize U.S. time-use data from 2003 to 2023. Through line charts and comparative bar charts, we explored how average daily time spent alone changed across age groups, translating a structured dataset into visual comparisons. 这是一个使用 Python 完成的小组编程与数据可视化项目。 我们处理并呈现了 2003 至 2023 年美国的时间使用数据， 通过折线图与对比柱状图，探索不同年龄群体日均独处时间的变化， 将结构化数据转化为直观的视觉比较。

Project Overview 项目概述

How has average daily time spent alone changed across different age groups? We used this question to guide the final analysis, comparing long-term trends and differences between 2003 and 2023. The project focused on using code to organize data and create charts that make these patterns easier to examine. 不同年龄群体的日均独处时间如何随年份变化？ 最终分析围绕这一问题展开，比较长期变化趋势， 以及 2003 年与 2023 年之间的群体差异。 项目的重点是通过代码整理数据并生成图表， 让这些变化更容易被观察和理解。

Dataset & Scope 数据来源与范围

The final analysis used the Our World in Data dataset on who Americans spend their time with, based on U.S. Bureau of Labor Statistics data. We focused on year, age group, and average daily time spent alone. 最终分析使用 Our World in Data 整理的美国人际相处时间数据， 原始数据来自美国劳工统计局。 我们重点关注年份、年龄群体及日均独处时间。

  • Period: 2003–2023. 时间范围：2003—2023 年。
  • Age groups: 15–29, 30–44, 45–59, and 60+ years. 年龄分组： 15—29 岁、30—44 岁、45—59 岁及 60 岁以上。
  • Measure: Average daily time spent alone, measured in hours. 主要指标： 日均独处时间，以小时为单位。

Python & Visualization Process Python 与可视化过程

We used Python to organize the CSV data for comparison by year and age group, then generate visualizations for the final presentation. 我们使用 Python 整理 CSV 数据， 按年份和年龄群体进行比较， 并生成用于最终展示的数据图表。

  • Data preparation: Select the relevant variables and organize observations for time-based comparisons. 数据整理： 选取相关变量，整理用于时间趋势比较的数据。
  • Line charts: Show changes over time and compare trends across age groups. 折线图： 展示随时间发生的变化，并比较不同年龄群体的趋势。
  • Comparative bar charts: Compare the beginning and end of the study period to highlight differences in change. 对比柱状图： 比较研究期起点与终点，呈现各群体变化幅度的差异。
  • Visual communication: Use titles, labels, and distinct colors to support interpretation of the charts. 视觉表达： 通过标题、标签与颜色区分，帮助读者理解图表。

Patterns Revealed by the Charts 图表呈现的变化

  • Average daily time spent alone increased across the age groups examined over the study period. 在研究期内，所分析年龄群体的日均独处时间整体增加。
  • The 60+ group consistently recorded the highest daily time spent alone. 60 岁以上群体的日均独处时间持续处于最高水平。
  • The 15–29 group showed the largest percentage increase between 2003 and 2023. 15—29 岁群体在 2003 至 2023 年间的独处时间百分比增幅最大。

These charts describe patterns in time use. Time spent alone does not directly measure loneliness, and the visualizations alone cannot establish the causes of these changes. 这些图表呈现的是时间使用规律。 独处时间不直接等同于孤独感， 也无法仅凭图表确定变化的原因。

Project Reflection 项目反思

This project connected Python programming with visual communication. Working with the same dataset across different chart types helped us consider how visual choices shape a reader's understanding of trends and comparisons. It also reinforced the importance of defining a clear question and distinguishing observable patterns from explanations. 这个项目将 Python 编程与视觉表达结合起来。 使用不同图表呈现同一组数据， 让我们更关注图表选择如何影响读者对趋势与差异的理解。 同时，也让我们认识到明确分析问题、 区分数据现象与原因解释的重要性。
